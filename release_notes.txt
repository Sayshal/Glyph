## Bug Fixes

- Minstrel `activeMood()` works again with Minstrel's stacking mood system and returns the name of the most recently started mood, or null when none is active.
- Set Mood (Minstrel) works again with Minstrel's stacking mood system, and Stop with a blank Mood Id stops all active moods.
- Set Shop Goodwill (Peddler) works again with Peddler's goodwill system and now requires a Character, setting that character's base goodwill with the shop.
