## New Features

- 40 ready-made example triggers across audio, messaging, scene, tile, token, variables, tagger, fxmaster, and logic categories, applicable directly from the config UI as a starting point.
- A History tab logs each trigger's past runs for troubleshooting.
- A Monks Active Tile Triggers importer converts an existing tile's actions into a glyph program automatically, reporting which actions converted cleanly, which converted partially (e.g. MATT's own `{{value}}` templates need manual rewriting), and which need manual review.
- A Tile can be linked to its Region so the Region's shape stays synced to the tile automatically.
- An expression engine for conditions and filters, with built-in functions for distance, line of sight, actor attributes, conditions, items, random chance, counting a collection, and per-behavior variables, plus `any()`/`all()` quantifiers over a collection.
- Named variables can be stored and read back per trigger, with their own Variables tab and a `variable()` expression function.
- Optional deeper integrations light up automatically when their module is active: Calendaria (season/weather/moon/calendar), Bondsmith (reputation, faction membership), Tenacity, Minstrel (mood, soundboard, ducking), Peddler (shop, restock, trust/pricing), Hero Mancer (level-up), Don't Forget (reminders), Spell Book, Mindful Encounters (dungeon turns, party budget), Token Light Condition, VG Music, Tagger, and FXMaster weather effects.
- Over 60 actions spanning tokens (move, rotate, create, delete, add/remove items, toggle conditions, roll tables, target), tiles (change/temp image, video, visibility, occlusion), scenes (pause game, change scene/background, adjust darkness, wall/door state, pan canvas, add to combat, change permissions, run a macro or arbitrary JS), audio (play/stop sound, play playlist), and messaging (chat message, notification, scrolling text, dialogs, open a journal or actor sheet, write to a journal).
- Per-trigger gating: restrict to players or the GM, roll a percent chance, require a minimum number of tokens, apply a cooldown, track per-token firing, require line of sight, or allow firing while the game is paused.
- Triggers respond to every core Region event (enter, exit, move, turn, etc.) plus pseudo-events glyph adds itself: hover in/out, click/right-click/double-click, world time or darkness changes, door opened/closed/locked/unlocked/revealed, and calendar-driven events (season, weather, day, moon phase, rest day, calendar event, character created).
- Visual, node-based trigger editor built into the Region's own behavior config (a Program tab replacing Foundry's generic sheet): build if/else branches, forEach loops, goto/landing jumps, and waits by composing nodes, no macro code or `eval()` required.
